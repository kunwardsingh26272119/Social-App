# ⚙ Installation

Clone the repository:

```bash
git clone https://github.com/kunwardsingh26272119/Social-App.git
```

Go to the project folder:

```bash
cd Social-App
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
